Input surface

Start match is the only required input. It also unlocks speech on iOS, which needs a user gesture.

Objective ended is the primary button, four to six times a match, during the regroup after a fight.

Camp chips are the rail entries themselves, tappable only while a camp is believed available. No separate row of camp buttons. The tap does not record who took it; the respawn is the same either way.

The clock is tappable to nudge the match start, since that is the one required input that is easy to fumble.

Undo appears briefly after any anchor. Anchors overwrite rather than accumulate, so undo restores one previous value and there is no undo stack.

Camp availability decays. Freshly spawned reads exact, then estimated, then unknown, shown as ? on the desktop rail above. Forgetting a camp tap produces silence rather than a false claim that a camp is still there.
